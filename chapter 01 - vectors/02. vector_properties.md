# Свойства векторов

*Свойства векторов описывают геометрические и алгебраические характеристики, определяющие поведение векторов. В этом файле рассматриваются длина, направление, единичные векторы, равенство, параллельность, ортогональность и линейная независимость — строительные блоки любого пространства признаков в МО.*

- **Длина** (или модуль) вектора показывает, *как далеко* он простирается. Думайте об этом как о длине стрелки. Для вектора $\mathbf{a} = (a_1, a_2, a_3)$ его длина равна:

$$\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

- Это просто теорема Пифагора, расширенная на большее число измерений, и измеряющая расстояние по прямой от начала координат до точки.

- **Направление** вектора показывает, *куда* он указывает; просто представьте прямую линию от начала координат до точки с этими координатами.

- Когда начало координат явно не указано, мы обычно подразумеваем точку (0,0,...,0), центральную точку, по крайней мере для целей визуализации.

- Положение неважно, важно только смещение: вектор $(3, 2)$, отложенный от начала координат, и такой же вектор $(3, 2)$, отложенный от другой точки, всё ещё равны.

![Равенство векторов: один и тот же вектор (3,2), отложенный из двух разных начальных точек|329](../images/vector_equality.svg)

- Два вектора могут иметь одинаковую длину, но указывать в совершенно разных направлениях, или указывать в одну сторону, но отличаться по длине.

![Одинаковое направление, разная длина (v и 2v) против одинаковой длины, разных направлений](../images/magnitude_direction.svg)

- Два вектора **равны** тогда и только тогда, когда все их соответствующие компоненты совпадают: та же длина, то же направление, абсолютно та же стрелка.

$$\mathbf{a} = \mathbf{b} \iff a_i = b_i \text{ для всех } i$$

- Два вектора **параллельны**, если один из них является скалярным кратным другого. Они лежат вдоль одной и той же линии — либо в одном направлении, либо строго в противоположном.

$$\mathbf{a} \parallel \mathbf{b} \iff \mathbf{a} = k\mathbf{b} \text{ для некоторого скаляра } k \neq 0$$

![Параллельные векторы: a и b указывают в одну сторону, a и -b — в противоположные](../images/parallel_vectors.svg)

- Если $k > 0$, они указывают в одну сторону. Если $k < 0$ — в противоположные. В любом случае они лежат на одной прямой, проходящей через начало координат.

- Интуитивно параллельные векторы не несут никакой «новой» информации о направлении. Один — просто растянутая или отражённая версия другого.

- Два вектора **ортогональны** (перпендикулярны), если они указывают в совершенно независимых направлениях. Движение вдоль одного не даёт никакого продвижения вдоль другого.

![Ортогональные векторы: u и v образуют прямой угол](../images/orthogonal_vectors.svg)

- Представьте, что вы идёте на север, а затем на восток — это ортогональные направления: сколько бы вы ни шли на север, вы никогда не сдвинетесь на восток. Мы будем очень часто встречать ортогональность.

- Ортогональность играет центральную роль в МО: признаки, которые ортогональны друг другу, несут абсолютно независимую информацию, что идеально для представления данных.

- В более общем случае между любыми двумя векторами существует **угол** $\theta$, изменяющийся от $0°$ до $180°$.

- Этот угол полностью описывает отношение между двумя направлениями: $0°$ означает параллельность (одинаковое направление), $180°$ — параллельность (противоположное направление), а $90°$ — ортогональность. Всё, что между ними, — некоторое сочетание.

- Большинство отношений между векторами в МО находятся где-то в этом спектре. Позже мы увидим точные инструменты (скалярное произведение, косинусное сходство) для вычисления этого угла.

- Набор векторов является **линейно зависимым**, если хотя бы один из них можно построить из остальных путём масштабирования и сложения. Он не привносит в набор ничего нового.

- Например, если $\mathbf{c} = 2\mathbf{a} + 3\mathbf{b}$, то $\mathbf{c}$ избыточен — всё, что предлагает $\mathbf{c}$, уже есть в $\mathbf{a}$ и $\mathbf{b}$.

- Параллельные векторы всегда линейно зависимы, поскольку один является просто масштабированной копией другого. Любой набор, содержащий нулевой вектор, также линейно зависим.

- Векторы **линейно независимы**, если ни один из них нельзя построить из остальных. Каждый из них вносит по-настоящему новое направление. Ортогональные векторы всегда линейно независимы.

- Немного интуиции: если вы хотите изучать разных людей и представлять их в виде векторов, линейно зависимые векторы (люди) исказят наблюдение в пользу переизбыточно представленной точки данных — важный фактор при проектировании набора данных для обучения ИИ.

- В 2D два линейно независимых вектора могут достичь любой точки плоскости. В 3D для этого нужно уже три вектора. Эта идея «сколько независимых векторов нужно» напрямую связана с размерностью.

- Вектор называется **разреженным (sparse)**, когда большинство его компонент равны нулю. Противоположность, когда большинство компонент ненулевые, называется **плотным (dense)**.

$$\mathbf{s} = [0, 0, 3, 0, 0, 0, 1, 0, 0, 0]$$

- Разреженность важна, поскольку она влияет как на хранение данных, так и на вычисления. Разреженные векторы можно хранить и обрабатывать гораздо эффективнее, отслеживая только ненулевые элементы.

- **Единичный вектор** — это вектор с длиной ровно 1. Он выражает исключительно направление, без информации о длине. Любой вектор можно превратить в единичный, разделив его на его длину:

$$\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$

- Этот процесс называется **нормализацией**. Он убирает «насколько далеко» и оставляет только «в какую сторону» — это важный момент в машинном обучении.

- Стандартные единичные векторы указывают вдоль каждой оси: $\hat{\mathbf{i}} = (1, 0, 0)$, $\hat{\mathbf{j}} = (0, 1, 0)$, $\hat{\mathbf{k}} = (0, 0, 1)$. Любой вектор можно записать как их комбинацию, например $(3, 2, 4) = 3\hat{\mathbf{i}} + 2\hat{\mathbf{j}} + 4\hat{\mathbf{k}}$.

## Практические задания (используйте CoLab или блокнот)

1. Вычислите длину вектора и убедитесь, что она совпадает с теоремой Пифагора, затем измените код, чтобы вычислить единичный вектор.
```python
import jax.numpy as jnp

a = jnp.array([3.0, 4.0])

magnitude = jnp.sqrt(jnp.sum(a ** 2))
print(f"Magnitude of a: {magnitude}") 
```

2. Проверьте, параллельны ли два вектора, проверив, является ли один из них скалярным кратным другого.
```python
import jax.numpy as jnp

a = jnp.array([2, 4, 6])
b = jnp.array([1, 2, 3])

ratios = a / b
print(f"Ratios: {ratios}")
print(f"Parallel: {jnp.allclose(ratios, ratios[0])}")
```
