# Интегральное исчисление

*Интегральное исчисление накапливает величины на интервалах, превращая локальные скорости обратно в итоговые суммы. В этом файле рассматриваются определённые и неопределённые интегралы, основная теорема анализа, методы интегрирования, а также применения к плотностям вероятности и математическим ожиданиям в МО.*

- Дифференцирование говорит нам о скорости изменения в одной точке. Интегрирование действует в обратную сторону: оно накапливает множество крошечных кусочков, чтобы вычислить итог.

- Если производная отвечает на вопрос «насколько быстро?», то интеграл отвечает на вопрос «сколько всего?»

- Самый простой способ представить интегрирование — это **площадь под кривой**. Если вы построите график функции $f(x)$ и закрасите область между кривой и осью x от $x = a$ до $x = b$, интеграл даст знаковую площадь этой области.

![Интегрирование вычисляет площадь под кривой, суммируя тонкие прямоугольники](../images/area_under_curve.svg)

- Почему «знаковую»? Области выше оси x дают положительную площадь, области ниже — отрицательную. Это имеет физический смысл: если $f(x)$ представляет скорость, интеграл даёт чистое перемещение (вперёд минус назад), а не общее пройденное расстояние.

- Чтобы вычислить эту площадь, представьте, что область разрезана на $n$ тонких вертикальных прямоугольников, каждый шириной $\Delta x$. Высота каждого прямоугольника — это значение функции в некоторой точке этого среза. Сложите их все:

$$\text{Площадь} \approx \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- По мере того как прямоугольники становятся всё тоньше и тоньше ($n \to \infty$, $\Delta x \to 0$), сумма становится точной. Этот предельный процесс определяет **определённый интеграл**:

$$\int_a^b f(x)\, dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i^\ast) \, \Delta x$$

- Символ $\int$ — это вытянутая буква «S», означающая «сумма». Символ $dx$ напоминает нам, что мы суммируем бесконечно тонкие срезы вдоль оси x.

- **Неопределённый интеграл** (или **первообразная**) — это функция $F(x)$, производная которой равна $f(x)$. Мы записываем это так:

$$\int f(x)\, dx = F(x) + C$$

- $+ C$ — это **постоянная интегрирования**. Поскольку производная любой константы равна нулю, существует бесконечно много первообразных, отличающихся лишь на константу. Например, $\int 2x\, dx = x^2 + C$, потому что производная $x^2 + 7$ или $x^2 - 3$ всё равно равна $2x$.

- **Основная теорема анализа (математического анализа)** — это мост, соединяющий дифференцирование и интегрирование. Она состоит из двух частей:

- **Часть 1**: если $F(x)$ — первообразная $f(x)$, то определённый интеграл равен разности значений $F$ на концах отрезка:

$$\int_a^b f(x)\, dx = F(b) - F(a)$$

- Это удивительно практично. Вместо вычисления предела сумм (что сложно), мы находим первообразную и вычисляем её в двух точках (что обычно легко).

- **Часть 2**: если определить $F(x) = \int_a^x f(t)\, dt$, то $F'(x) = f(x)$. Дифференцирование и интегрирование — обратные операции, они отменяют друг друга.

- Например, чтобы вычислить $\int_1^3 x^2\, dx$: первообразная $x^2$ — это $\frac{x^3}{3}$. Значит, $\int_1^3 x^2\, dx = \frac{27}{3} - \frac{1}{3} = \frac{26}{3} \approx 8.67$.

- Так же как у дифференцирования есть правила, у интегрирования есть соответствующие правила, обращающие их:

| Функция | Интеграл | Условие |
|---|---|---|
| $x^n$ | $\frac{x^{n+1}}{n+1} + C$ | $n \neq -1$ |
| $\frac{1}{x}$ | $\ln\|x\| + C$ | |
| $e^x$ | $e^x + C$ | |
| $a^x$ | $\frac{a^x}{\ln a} + C$ | |
| $\sin x$ | $-\cos x + C$ | |
| $\cos x$ | $\sin x + C$ | |
| $k$ (константа) | $kx + C$ | |

- **Правило суммы/разности** переносится и сюда: $\int [f(x) \pm g(x)]\, dx = \int f(x)\, dx \pm \int g(x)\, dx$. Константы можно выносить за знак интеграла: $\int k\, f(x)\, dx = k \int f(x)\, dx$.

- Когда функцию слишком сложно проинтегрировать напрямую, у нас есть методы для её упрощения.

- **Замена переменной (u-подстановка)** — это обратное к цепному правилу. Если вы замечаете составную функцию $f(g(x))$, умноженную на $g'(x)$, подставьте $u = g(x)$, так что $du = g'(x)\, dx$, и интеграл упростится.

- Например: $\int 2x \cos(x^2)\, dx$. Пусть $u = x^2$, тогда $du = 2x\, dx$. Интеграл становится $\int \cos(u)\, du = \sin(u) + C = \sin(x^2) + C$.

- **Интегрирование по частям** — это обратное к правилу произведения. Если подынтегральное выражение является произведением двух функций:

$$\int u\, dv = uv - \int v\, du$$

- Выбирайте $u$ и $dv$ стратегически, чтобы оставшийся интеграл $\int v\, du$ был проще исходного. Распространённая мнемоника для выбора $u$ — **ЛОАТП** (или английская **LIATE**): Логарифмические, Обратные тригонометрические, Алгебраические, Тригонометрические, Показательные (выбирайте $u$ из более ранней категории).

- Например: $\int x\, e^x\, dx$. Пусть $u = x$ (алгебраическая функция) и $dv = e^x\, dx$. Тогда $du = dx$ и $v = e^x$. Итак: $\int x\, e^x\, dx = x\, e^x - \int e^x\, dx = x\, e^x - e^x + C = e^x(x - 1) + C$.

- В МО интегрирование встречается в теории вероятностей (вычисление вероятностей через интегрирование функций плотности), в математических ожиданиях (взвешенные средние по непрерывным распределениям) и при вычислении площади под ROC-кривыми. Хотя на практике мы редко интегрируем вручную, понимание смысла интегрирования помогает интерпретировать эти величины.

## Практические задания (используйте CoLab или блокнот)

1. Численно приблизьте $\int_0^1 x^2\, dx$ с помощью суммы Римана, увеличивая число прямоугольников. Сравните с точным ответом $\frac{1}{3}$.
```python
import jax.numpy as jnp

for n in [10, 100, 1000, 10000]:
    x = jnp.linspace(0, 1, n, endpoint=False)
    dx = 1.0 / n
    area = jnp.sum(x**2 * dx)
    print(f"n={n:5d}  approx: {area:.6f}  exact: {1/3:.6f}")
```

2. Проверьте основную теорему анализа численно. Определите $F(x) = \int_0^x t^2\, dt = \frac{x^3}{3}$ и убедитесь, что её производная (вычисленная через `jax.grad`) равна $x^2$.
```python
import jax
import jax.numpy as jnp

F = lambda x: x**3 / 3
dF = jax.grad(F)

for x in [0.5, 1.0, 2.0, 3.0]:
    print(f"x={x:.1f}  F'(x)={dF(x):.4f}  x^2={x**2:.4f}")
```

3. Визуализируйте площадь под $f(x) = \sin(x)$ от $0$ до $\pi$. Используйте `plt.fill_between`, чтобы закрасить область, и вычислите площадь численно с помощью суммы Римана.
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

x = jnp.linspace(0, jnp.pi, 500)
y = jnp.sin(x)

plt.plot(x, y, color="purple", linewidth=2)
plt.fill_between(x, y, alpha=0.2, color="purple")
plt.title(f"Area = {jnp.sum(jnp.sin(x) * (jnp.pi / 500)):.4f}  (exact: 2.0)")
plt.show()
```
