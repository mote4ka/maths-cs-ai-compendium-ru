# Дифференциальное исчисление

*Дифференциальное исчисление фиксирует мгновенные скорости изменения. В этом файле рассматриваются пределы, производные, правила дифференцирования, цепное правило (основа обратного распространения ошибки) и распространённые производные, используемые повсюду в МО.*

- В предыдущих главах мы научились представлять данные в виде векторов и преобразовывать их с помощью матриц. Но многие явления реального мира не статичны. Автомобиль ускоряется, цена акции колеблется, потери нейронной сети меняются по мере обновления весов. **Математический анализ (исчисление)** — это математика изменения.

- Анализ задаёт два вопроса: насколько быстро что-то меняется прямо сейчас? (дифференциальное исчисление) и сколько всего накопилось со временем? (интегральное исчисление). Этот раздел посвящён вопросу «насколько быстро».

- Представьте, что вы за рулём и смотрите на спидометр. Он показывает 60 км/ч. Это число не является средней скоростью всей вашей поездки — это ваша скорость именно в этот момент. Дифференциальное исчисление даёт нам инструменты для вычисления таких мгновенных скоростей изменения.

- Но сначала вспомним уравнение прямой линии: $y = mx + b$.

- Это простейшее отношение между двумя величинами.

    - $b$ — это **точка пересечения с осью y**, где линия пересекает ось y (начальное значение при $x = 0$).
    - $m$ — это **наклон**, скорость изменения: при увеличении $x$ на 1 единицу $y$ меняется на $m$.
- Если $m = 3$, линия круто поднимается; если $m = 0$, линия плоская; если $m = -2$, линия падает.

- Наклон вычисляется как $m = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$ — отношение «насколько изменилось $y$» к «насколько изменилось $x$».

![Уравнение прямой: b — точка пересечения с осью y, m — наклон (подъём на пробег)](../images/line_equation.svg)

- Зная $m$ и $b$, можно вычислить $y$ для любого $x$.

- Например, если $m = 2$ и $b = 3$, то при $x = 5$: $y = 2(5) + 3 = 13$.

- Эти два параметра полностью определяют линию, и предсказание любого выхода — это просто подстановка значения.

- Для прямой линии наклон одинаков везде.

- Эта идея обобщается за пределы прямых линий. Любая функция — это правило, отображающее входы в выходы, и, зная её формулу (параметры и форму), можно вычислить выход для любого входа и построить график результата.

- $y = x^2$ даёт параболу, $y = \sin(x)$ даёт волну, $y = e^x$ даёт экспоненциальный рост. Каждая формула определяет конкретную кривую, и умение читать функцию как форму жизненно важно для всего, что последует дальше.

- Для прямой линии наклон одинаков везде. Но большинство интересных функций изогнуты, поэтому наклон меняется от точки к точке. Математический анализ даёт нам способ найти наклон в любой отдельной точке кривой.

- Нам также нужно понятие **предела**. Предел описывает, к какому значению приближается функция по мере того, как её вход подходит всё ближе и ближе к некоторой цели, не обязательно достигая её.

$$\lim_{x \to a} f(x) = L$$

- Это читается так: «когда $x$ приближается к $a$, $f(x)$ приближается к $L$». Функции не обязательно фактически равняться $L$ при $x = a$. Она просто должна подходить сколь угодно близко.

- Например, возьмём $f(x) = \frac{x^2 - 1}{x - 1}$. Если подставить $x = 1$ напрямую, получим $\frac{0}{0}$, что не определено.

- Но попробуем значения, близкие к 1: $f(0.9) = 1.9$, $f(0.99) = 1.99$, $f(1.01) = 2.01$. Результаты явно стремятся к 2.

- Алгебраически видно почему: разложим числитель как $(x-1)(x+1)$, сократим члены $(x-1)$, и получим $f(x) = x + 1$ для всех $x \neq 1$. Так что при $x \to 1$, $f(x) \to 2$.

- В функции есть «дыра» при $x = 1$, но предел всё равно существует.

- Пределы — это фундамент, на котором держится всё остальное в математическом анализе.

- **Производная** функции $f(x)$ в точке $x = a$ измеряет мгновенную скорость изменения. Геометрически это наклон касательной линии к кривой в этой точке.

![Производная — это наклон касательной линии в точке на кривой](../images/tangent_line.svg)

- Чтобы вычислить этот наклон, начнём с двух точек на кривой и вычислим наклон линии, проходящей через них (**секущая линия**). Затем сдвигаем вторую точку всё ближе и ближе к первой и смотрим, к какому наклону приближается секущая. Это **разностное отношение**:

$$f'(a) = \lim_{h \to 0} \frac{f(a + h) - f(a)}{h}$$

![По мере уменьшения h секущая линия приближается к касательной](../images/difference_quotient.svg)

- Числитель $f(a+h) - f(a)$ — это изменение выхода. Знаменатель $h$ — это изменение входа. Их отношение — средняя скорость изменения на крошечном интервале. При $h \to 0$ это среднее становится мгновенной скоростью.

- Например, пусть $f(x) = x^2$. При $x = 3$:

$$f'(3) = \lim_{h \to 0} \frac{(3+h)^2 - 9}{h} = \lim_{h \to 0} \frac{9 + 6h + h^2 - 9}{h} = \lim_{h \to 0} (6 + h) = 6$$

- Итак, при $x = 3$ функция $x^2$ возрастает со скоростью 6 единиц выхода на единицу входа.

- Функция **дифференцируема** в точке, если этот предел существует. Для этого функция должна быть непрерывной (без скачков), гладкой (без острых углов) и определённой в окрестности этой точки.

- Если вы можете нарисовать кривую, не отрывая ручку от бумаги и без каких-либо изломов, она, вероятно, дифференцируема в этой точке.

- Вычислять производные из определения через предел каждый раз было бы утомительно. К счастью, горстка правил позволяет быстро дифференцировать почти любую функцию.

- **Правило константы**: производная константы равна нулю. Если $f(x) = 5$, то $f'(x) = 0$. У плоской линии нулевой наклон.

- **Степенное правило**: рабочая лошадка дифференцирования. Опустите показатель степени и уменьшите его на единицу:

$$\frac{d}{dx} x^n = n x^{n-1}$$

- Например: $\frac{d}{dx} x^3 = 3x^2$. Кубическая функция становится квадратичной. Это работает для любого вещественного показателя степени, включая отрицательные и дробные: $\frac{d}{dx} x^{-1} = -x^{-2}$ и $\frac{d}{dx} \sqrt{x} = \frac{d}{dx} x^{1/2} = \frac{1}{2}x^{-1/2}$.

- **Правило суммы/разности**: дифференцируйте почленно.

$$\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$$

- **Правило произведения**: когда две функции перемножаются, производная — это не просто произведение производных. Вместо этого:

$$\frac{d}{dx}[f(x) \cdot g(x)] = f'(x)g(x) + f(x)g'(x)$$

- Думайте об этом так: «скорость изменения первой функции, умноженная на вторую, плюс первая функция, умноженная на скорость изменения второй». Например, $\frac{d}{dx}[x^2 \sin x] = 2x \sin x + x^2 \cos x$.

- **Правило частного**: для отношения функций:

$$\frac{d}{dx}\left[\frac{f(x)}{g(x)}\right] = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$$

- Полезная мнемоника: «низ, умноженный на производную верха, минус верх, умноженный на производную низа, всё делённое на квадрат того, что внизу».

- **Цепное правило**: важнейшее правило для МО. Когда функции составлены (одна внутри другой), производная — это произведение производных вдоль цепочки:

$$\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)$$

- Думайте об этом как о чистке луковицы. Продифференцируйте внешнюю функцию (не трогая внутреннюю), затем умножьте на производную внутренней функции.

![Цепное правило: продифференцировать внешнюю функцию, умножить на производную внутренней](../images/chain_rule.svg)

- Например, $\frac{d}{dx} (3x + 1)^5 = 5(3x+1)^4 \cdot 3 = 15(3x+1)^4$. Внешняя функция — это $(\cdot)^5$, а внутренняя — $3x+1$.

- Цепное правило — это математическая основа **обратного распространения ошибки (backpropagation)** в нейронных сетях. Глубокая сеть — это длинная цепочка составленных функций. Чтобы вычислить, как потери меняются относительно каждого веса, мы многократно применяем цепное правило от выходного слоя обратно ко входу, перемножая локальные производные на каждом шаге.

- Вот самые распространённые производные, которые вам встретятся. Каждую из них можно вывести из определения через предел, но знание их наизусть экономит время:

| Функция | Производная | Примечания |
|---|---|---|
| $e^x$ | $e^x$ | Единственная функция, которая равна своей собственной производной |
| $a^x$ | $a^x \ln a$ | Обобщает экспоненту |
| $\ln x$ | $\frac{1}{x}$ | Натуральный логарифм |
| $\log_a x$ | $\frac{1}{x \ln a}$ | Логарифм по произвольному основанию |
| $\sin x$ | $\cos x$ | |
| $\cos x$ | $-\sin x$ | Обратите внимание на знак минус |
| $\tan x$ | $\sec^2 x$ | |

- Экспоненциальная функция $e^x$ примечательна: это единственная функция, которая равна своей собственной производной. Именно поэтому $e$ встречается повсюду в МО — от softmax-активаций до распределений вероятностей.

- **Правило Лопиталя** обрабатывает пределы, дающие неопределённости вида $\frac{0}{0}$ или $\frac{\infty}{\infty}$. Когда прямая подстановка даёт одну из этих форм, можно взять производную числителя и знаменателя по отдельности и снова попробовать вычислить предел:

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

- Условия: и $f$, и $g$ должны быть дифференцируемы вблизи $a$, а $g'(x) \neq 0$ вблизи $a$ (кроме, возможно, самой точки $a$). Исходный предел должен давать неопределённость.

- Например: $\lim_{x \to 0} \frac{\sin x}{x}$. Прямая подстановка даёт $\frac{0}{0}$. Применяя правило Лопиталя: $\lim_{x \to 0} \frac{\cos x}{1} = 1$. Этот предел фундаментален, он встречается в обработке сигналов и анализе Фурье.

- Правило можно применять многократно, если результат по-прежнему неопределён. Например, $\lim_{x \to 0} \frac{1 - \cos x}{x^2}$ даёт $\frac{0}{0}$. Первое применение: $\lim_{x \to 0} \frac{\sin x}{2x}$, всё ещё $\frac{0}{0}$. Второе применение: $\lim_{x \to 0} \frac{\cos x}{2} = \frac{1}{2}$.

- Если две функции дифференцируемы, их сумма, разность, произведение, композиция и частное (где знаменатель не равен нулю) также дифференцируемы. Именно поэтому мы можем уверенно дифференцировать сложные выражения, построенные из простых частей.

1. Визуализируйте распространённые функции. Постройте графики $x^2$, $\sin(x)$ и $e^x$ рядом друг с другом, чтобы выработать интуицию о том, как разные формулы порождают разные формы. Попробуйте изменить параметры (например, $2x^2$, $\sin(2x)$) и понаблюдайте, как меняются кривые.
```python
import jax.numpy as jnp
import matplotlib.pyplot as plt

x = jnp.linspace(-3, 3, 300)

fig, axes = plt.subplots(1, 3, figsize=(12, 3))
axes[0].plot(x, x**2, color="#e74c3c")

axes[2].set_title("eˣ  (exponential)")

    ax.axhline(0, color="gray", linewidth=0.5)
    ax.axvline(0, color="gray", linewidth=0.5)

```

2. Используйте автоматическое дифференцирование JAX, чтобы вычислить производную $f(x) = x^3 - 2x + 1$ в нескольких точках. Сравните с аналитической производной $f'(x) = 3x^2 - 2$.
```python
import jax
import jax.numpy as jnp

f = lambda x: x**3 - 2*x + 1
df = jax.grad(f)

for x in [0.0, 1.0, 2.0, -1.0]:
    print(f"x={x:5.1f}  autodiff: {df(x):.4f}  analytical: {3*x**2 - 2:.4f}")
```

2. Проверьте цепное правило численно. Определите $f(x) = \sin(x^2)$, вычислите её производную через `jax.grad` и сравните с аналитическим результатом $2x\cos(x^2)$.
```python
import jax
import jax.numpy as jnp

f = lambda x: jnp.sin(x**2)
df = jax.grad(f)

for x in [0.5, 1.0, 2.0]:
    auto = df(x)
    analytical = 2*x * jnp.cos(x**2)
    print(f"x={x:.1f}  autodiff: {auto:.6f}  analytical: {analytical:.6f}")
```

3. Визуализируйте производную. Постройте график $f(x) = x^3 - 3x$ и её производной $f'(x) = 3x^2 - 3$ на одном графике. Обратите внимание, что $f'(x) = 0$ соответствует пикам и впадинам функции $f$.
```python
import jax
import jax.numpy as jnp
import matplotlib.pyplot as plt

f = lambda x: x**3 - 3*x
# jax.grad works on scalars; jax.vmap vectorises it to operate on an array of inputs at once
df = jax.vmap(jax.grad(f))

x = jnp.linspace(-2.5, 2.5, 200)
plt.plot(x, jax.vmap(f)(x), label="f(x)")
plt.plot(x, df(x), label="f'(x)", linestyle="--")
plt.axhline(0, color="gray", linewidth=0.5)
plt.legend()
plt.title("A function and its derivative")
plt.show()
```
