# Оптимизация

*Оптимизация — это математическое ядро обучения моделей, поиск параметров, минимизирующих функцию потерь. В этом файле рассматриваются критические точки, выпуклость, градиентный спуск, метод Ньютона, условная оптимизация с множителями Лагранжа, а также оптимизаторы (SGD, Adam), на которых работает современное глубокое обучение.*

- Обучение нейронной сети, подгонка линии регрессии, настройка гиперпараметров: в основе почти каждого алгоритма МО лежит задача **оптимизации**.

- У нас есть некоторая функция (потери, стоимость, целевая функция), и мы хотим найти входные значения, которые делают её как можно меньше (или больше).

- Прежде чем оптимизировать, нам нужно разобраться с **нулями** (или корнями) функций. Ноль функции $f(x)$ — это значение $x$, при котором $f(x) = 0$. Графически это точки пересечения с осью x.

- Например, $f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ имеет нули при $x = 1$ и $x = 2$. Между нулями функция отрицательна ($f(1.5) = -0.25$); за пределами нулей она положительна. Нули делят числовую прямую на области, где функция имеет постоянный знак.

- **Кратность** нуля — это сколько раз соответствующий множитель встречается в разложении.

- В простом нуле (кратность 1) график пересекает ось x. В двойном нуле (кратность 2) график касается оси x, но отскакивает назад, не пересекая её, выглядя «плоским» в этой точке.

- Поиск нулей важен, потому что нули производной $f'(x)$ являются **критическими точками** функции $f(x)$ — кандидатами на максимумы и минимумы.

- В максимуме или минимуме касательная линия плоская (наклон = 0), поэтому $f'(x) = 0$.

![Критические точки: там, где производная равна нулю, у функции есть пик, впадина или седло](../../images/critical_points.svg)

- Но не каждая критическая точка является максимумом или минимумом. Точка, где $f'(x) = 0$, может также быть **точкой перегиба** (как $x = 0$ для $f(x) = x^3$), где функция на мгновение выравнивается, но не меняет направление.

- **Тест второй производной** разрешает эту неоднозначность. В критической точке $x = c$, где $f'(c) = 0$:

    - Если $f''(c) > 0$: кривая выпукла вверх (как чаша), значит $c$ — **локальный минимум**.
    - Если $f''(c) < 0$: кривая выпукла вниз (как холм), значит $c$ — **локальный максимум**.
    - Если $f''(c) = 0$: тест неубедителен; нужны производные более высокого порядка или другие методы.

- Например, $f(x) = x^3 - 3x$. Производная равна $f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$, так что критические точки находятся при $x = -1$ и $x = 1$. Вторая производная равна $f''(x) = 6x$. При $x = -1$: $f''(-1) = -6 < 0$ (локальный максимум). При $x = 1$: $f''(1) = 6 > 0$ (локальный минимум).

- Функция **выпукла**, если отрезок между любыми двумя точками на её графике лежит выше графика (или на нём). Представьте это как форму чаши, изгибающейся вверх повсюду. Математически $f$ выпукла, если $f''(x) \geq 0$ для всех $x$.

![Выпуклые функции имеют единственный глобальный минимум; невыпуклые функции могут иметь много локальных минимумов](../../images/convex_nonconvex.svg)

- Выпуклость мощна, потому что у выпуклых функций есть примечательное свойство: каждый локальный минимум также является **глобальным минимумом**. Нет обманчивых локальных впадин, в которых можно застрять. Если закатить мяч в выпуклую чашу, он всегда докатится до дна.

- Функция **вогнута** (изгибается вниз), если $-f$ выпукла. Точки, где функция переходит между вогнутостью и выпуклостью, — это **точки перегиба**, происходящие там, где $f''(x) = 0$.

- **Метод Ньютона** находит нули функций (и, соответственно, критические точки их производных) с помощью касательных линий. Начиная с начального приближения $x_0$, он итеративно уточняет:

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

![Метод Ньютона: следование за касательной линией для нахождения лучшего приближения корня](../../images/newtons_method.svg)

- Идея: в точке $x_n$ проведите касательную линию и найдите, где она пересекает ось x. Эта точка пересечения становится $x_{n+1}$. Для «хорошо себя ведущих» функций с удачным начальным приближением метод Ньютона сходится очень быстро (квадратично, то есть число верных цифр примерно удваивается на каждом шаге).

- Например, чтобы найти $\sqrt{5}$ (ноль функции $f(x) = x^2 - 5$): $f'(x) = 2x$, так что $x_{n+1} = x_n - \frac{x_n^2 - 5}{2x_n}$. Начиная с $x_0 = 2$: $x_1 = 2.25$, $x_2 = 2.2361\ldots$, что уже точно до четырёх десятичных знаков.

- Метод Ньютона может не сработать, если начальное приближение далеко от корня, если $f'(x) = 0$ вблизи корня, или если у функции поблизости есть точки перегиба. Он также требует вычисления производной, что может быть затратно.

- Для оптимизации (поиска минимумов вместо нулей) мы применяем метод Ньютона к $f'(x) = 0$, что даёт обновление:

$$x_{n+1} = x_n - \frac{f'(x_n)}{f''(x_n)}$$

- В нескольких измерениях это становится $\mathbf{x}_{n+1} = \mathbf{x}_n - H^{-1} \nabla f(\mathbf{x}_n)$, где $H$ — матрица Гессе. Это в действии — аппроксимация Тейлора второго порядка из предыдущего файла: приблизить функцию как квадратичную, перепрыгнуть к минимуму этой квадратичной функции, повторить.

- **Множители Лагранжа** решают задачу **условной оптимизации**: найти оптимум $f(x, y)$ при ограничении $g(x, y) = c$. Вместо поиска по всему $\mathbb{R}^n$ мы ограничены множеством, где выполняется это ограничение (кривая или поверхность).

- Ключевая идея геометрическая: в точке условного оптимума градиент $f$ должен быть параллелен градиенту $g$. Если бы они не были параллельны, мы могли бы двигаться вдоль ограничения в направлении, которое всё ещё улучшает $f$, значит, мы ещё не достигли бы оптимума.

- Мы вводим новую переменную $\lambda$ (множитель Лагранжа) и определяем **лагранжиан**:

$$\mathcal{L}(x, y, \lambda) = f(x, y) - \lambda(g(x, y) - c)$$

- Приравнивание всех частных производных к нулю даёт систему уравнений, решения которой являются условными оптимумами:

$$\frac{\partial \mathcal{L}}{\partial x} = 0, \quad \frac{\partial \mathcal{L}}{\partial y} = 0, \quad \frac{\partial \mathcal{L}}{\partial \lambda} = 0$$

![Множители Лагранжа: в оптимуме градиенты f и g параллельны](../../images/lagrange_multiplier.svg)

- Например, максимизируем $f(x,y) = x^2 y$ при ограничении $x^2 + y^2 = 1$. Лагранжиан равен $\mathcal{L} = x^2 y - \lambda(x^2 + y^2 - 1)$. Беря частные производные:

$$2xy - 2\lambda x = 0, \quad x^2 - 2\lambda y = 0, \quad x^2 + y^2 = 1$$

- Из первого уравнения (предполагая $x \neq 0$): $\lambda = y$. Подставляя во второе: $x^2 = 2y^2$. В сочетании с ограничением: $2y^2 + y^2 = 1$, откуда $y = \frac{1}{\sqrt{3}}$. Максимальное значение равно $f = \frac{2}{3\sqrt{3}}$.

- Для ограничений-неравенств ($g(x,y) \leq c$ вместо $= c$) **условия Каруша–Куна–Таккера (KKT)** обобщают множители Лагранжа. Ограничение либо активно (связывающее, рассматривается как равенство), либо неактивно (решение лежит внутри области, и ограничение не имеет значения).

- На практике мы редко оптимизируем вручную. Вот основные семейства алгоритмов:

    - **Методы первого порядка** (используют только градиент): градиентный спуск, стохастический градиентный спуск (SGD), Adam. Они дёшевы на каждом шаге, но могут сходиться медленно, особенно на плохо обусловленных задачах.

    - **Методы второго порядка** (используют градиент и гессиан): метод Ньютона сходится быстро, но вычисление и обращение гессиана затратно ($O(n^3)$ для $n$ параметров). **Квазиньютоновские методы** (такие как BFGS и L-BFGS) приближают гессиан, используя только информацию о градиенте, достигая более быстрой сходимости, чем методы первого порядка, без полной стоимости методов второго порядка.

    - **Метод сопряжённых градиентов**: эффективен для больших разреженных систем, использует только произведения матрицы на вектор вместо хранения полного гессиана.

    - **Гаусса–Ньютона** и **Левенберга–Марквардта**: специализированы для задач наименьших квадратов (распространены в регрессии), приближают гессиан через якобиан.

    - **Естественный градиентный спуск**: учитывает геометрию пространства параметров с помощью информационной матрицы Фишера, что может быть более эффективно для вероятностных моделей.

- Выбор оптимизатора зависит от задачи. Для глубокого обучения преобладают методы первого порядка (особенно Adam), потому что число параметров огромно (от миллионов до миллиардов), что делает вычисление гессиана непрактичным. Для меньших задач с гладкими целевыми функциями методы второго порядка могут быть значительно быстрее.

## Практические задания (используйте CoLab или блокнот)

1. Реализуйте метод Ньютона для нахождения $\sqrt{7}$ (ноль функции $f(x) = x^2 - 7$). Понаблюдайте за быстрой сходимостью.
$$python
import jax.numpy as jnp

f = lambda x: x**2 - 7
df = lambda x: 2*x

x = 3.0  # initial guess
for i in range(6):
    x = x - f(x) / df(x)
    print(f"step {i+1}: x = {x:.10f}  (error: {abs(x - jnp.sqrt(7.0)):.2e})")
$$

2. Используйте градиентный спуск для минимизации $f(x, y) = (x - 3)^2 + (y + 1)^2$. Минимум находится в точке $(3, -1)$. Поэкспериментируйте с разными темпами обучения.
$$python
import jax
import jax.numpy as jnp

def f(params):
    x, y = params
    return (x - 3)**2 + (y + 1)**2

grad_f = jax.grad(f)
params = jnp.array([0.0, 0.0])
lr = 0.1

for i in range(20):
    g = grad_f(params)
    params = params - lr * g
    if i % 5 == 0 or i == 19:
        print(f"step {i:2d}: ({params[0]:.4f}, {params[1]:.4f})  loss={f(params):.6f}")
$$

3. Решите задачу условной оптимизации численно. Максимизируйте $f(x,y) = xy$ при ограничении $x + y = 10$, параметризовав $y = 10 - x$ и найдя оптимум одномерной функции.
$$python
import jax
import jax.numpy as jnp

# Substitute constraint: y = 10 - x, so f = x(10 - x) = 10x - x²
f = lambda x: x * (10 - x)
df = jax.grad(f)

# Gradient ascent (we want maximum, so add gradient)
x = 1.0
lr = 0.1
for i in range(20):
    x = x + lr * df(x)
print(f"x={x:.4f}, y={10-x:.4f}, f={f(x):.4f}")  # should be x=5, y=5, f=25
$$
