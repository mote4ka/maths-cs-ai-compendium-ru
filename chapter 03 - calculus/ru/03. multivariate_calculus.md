# Многомерное исчисление

*Многомерное исчисление расширяет производные и интегралы на функции многих переменных, что необходимо, поскольку модели МО имеют миллионы параметров. В этом файле рассматриваются частные производные, градиент, якобиан, гессиан и многомерное цепное правило, делающее возможным обратное распространение ошибки.*

- До сих пор наши функции принимали один вход $x$ и выдавали один выход $f(x)$. Но в МО мы почти никогда не работаем всего с одной переменной.

- Рассмотрим функцию двух переменных, например $f(x, y) = x^2 + y^2$. Она задаёт поверхность в 3D-пространстве в форме чаши. Мы хотим узнать: если немного сдвинуть $x$, оставив $y$ фиксированным, как изменится $f$? Это и есть **частная производная**.

- **Частная производная** $f$ по $x$, записываемая как $\frac{\partial f}{\partial x}$, рассматривает все остальные переменные как константы и дифференцирует как обычно по $x$.

- Для $f(x, y) = x^2y + 3x - 2y$:

$$\frac{\partial f}{\partial x} = 2xy + 3 \qquad \frac{\partial f}{\partial y} = x^2 - 2$$

- Чтобы вычислить $\frac{\partial f}{\partial x}$, мы рассматривали $y$ как константу, поэтому $x^2y$ продифференцировалось до $2xy$, $3x$ — до $3$, а $-2y$ — до $0$.

- Чтобы вычислить $\frac{\partial f}{\partial y}$, мы рассматривали $x$ как константу, поэтому $x^2y$ продифференцировалось до $x^2$, $3x$ — до $0$, а $-2y$ — до $-2$.

- Геометрически взятие частной производной по $x$ похоже на разрезание 3D-поверхности плоскостью, параллельной плоскости $xz$ (при фиксированном значении $y$), и нахождение наклона получившейся кривой.

![Частная производная: срез поверхности при фиксированной одной переменной](../images/partial_derivative.svg)

- **Градиент** собирает все частные производные в один вектор:

$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \ldots, \frac{\partial f}{\partial x_n}\right)$$

- Для $f(x, y) = x^2 + y^2$: $\nabla f(x, y) = (2x, 2y)$. В точке $(1, 2)$: $\nabla f(1, 2) = (2, 4)$.

- У градиента есть два ключевых свойства:

    - **Направление**: он указывает в направлении наибольшего возрастания. Представьте туриста на горе. Градиент в его позиции указывает прямо в гору, вдоль самого крутого пути.

    - **Величина**: $\|\nabla f\|$ даёт скорость возрастания в этом самом крутом направлении. Большой градиент означает крутой рельеф; маленький градиент означает, что рельеф почти плоский.

![Векторы градиента указывают вверх по склону, перпендикулярно линиям уровня](../images/gradient_contour.svg)

- Поскольку градиент указывает вверх по склону, движение в противоположном направлении ($-\nabla f$) идёт вниз, к меньшим значениям. Эта простая идея лежит в основе **градиентного спуска** — техники оптимизации, которую мы подробно изучим в последующих главах. Пока что важно запомнить: градиент показывает, где «вверх» и насколько крут подъём.

- **Производная по направлению** обобщает частные производные. Вместо вопроса «как меняется $f$ вдоль оси $x$?», она спрашивает «как меняется $f$ вдоль произвольного направления $\mathbf{u}$?» Она вычисляется как скалярное произведение градиента на единичный вектор:

$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u}$$

- Для $f(x, y) = x^2 + y^2$ в точке $(1, 2)$ в направлении $\mathbf{v} = (3, 4)$: сначала нормализуем, получая $\mathbf{u} = (3/5, 4/5)$, затем $D_{\mathbf{u}} f = (2, 4) \cdot (3/5, 4/5) = 6/5 + 16/5 = 22/5$.

- Частные производные — это частные случаи производных по направлению, где направление совпадает с координатной осью. Если производная по направлению равна нулю в некотором направлении, функция в этой точке плоская вдоль этого направления.

- **Линии уровня** (или контурные линии) соединяют точки, где функция имеет одно и то же значение. Для $f(x, y) = x^2 + y^2$ линии уровня — это окружности с центром в начале координат: $x^2 + y^2 = c$ для разных значений $c$.

- Линии уровня никогда не пересекаются друг с другом (точка не может иметь два разных значения функции).

- Градиент всегда перпендикулярен линиям уровня, указывая от меньших значений к большим.

- Тесно расположенные линии уровня указывают на крутой рельеф; редко расположенные линии — на пологие склоны.

- До сих пор наши функции давали один выход. Но многие функции дают несколько выходов. Функция $\mathbf{F}: \mathbb{R}^n \to \mathbb{R}^m$ принимает $n$ входов и выдаёт $m$ выходов. **Матрица Якоби (якобиан)** организует все частные производные такой векторнозначной функции:

```math
J = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}
```

- Каждая строка якобиана — это градиент одной компоненты выхода. Для функции с 3 входами и 2 выходами якобиан — это матрица $2 \times 3$.

- Якобиан обобщает понятие производной на векторнозначные функции.

- Так же как производная скалярной функции показывает, насколько меняется выход на единицу изменения входа, якобиан показывает, как каждый выход меняется относительно каждого входа.

- **Определитель якобиана** измеряет, насколько преобразование локально растягивает или сжимает пространство.

- Если определитель равен 2, малые области удваиваются по площади. Если он равен 0, преобразование сжимает пространство до меньшей размерности (вспомните из главы про матрицы, что нулевой определитель означает сингулярное, необратимое преобразование).

- Когда несколько преобразований составлены (одно подаётся на вход следующему), якобиан общего отображения равен произведению отдельных якобианов. Мы увидим, как эта идея становится центральной в последующих главах.

- Там, где градиент фиксирует информацию первого порядка (наклоны), **матрица Гессе (гессиан)** фиксирует информацию второго порядка (кривизну).

- Для скалярной функции $f(x_1, \ldots, x_n)$ гессиан — это матрица $n \times n$ всех вторых частных производных:

```math
H = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix}
```

- Для $f(x, y) = x^3 + 2xy^2 - y^3$ градиент равен $(3x^2 + 2y^2,\; 4xy - 3y^2)$, а гессиан:

```math
H = \begin{bmatrix} 6x & 4y \\ 4y & 4x - 6y \end{bmatrix}
```

- Диагональные элементы ($6x$ и $4x - 6y$) показывают, как меняется наклон в направлении $x$ при движении по $x$, и аналогично для $y$.

- Внедиагональные элементы ($4y$) показывают, как меняется наклон в одном направлении при движении в другом направлении.

- **Теорема Клеро** гарантирует, что для функций с непрерывными вторыми производными смешанные частные производные равны: $\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}$.

- Это означает, что гессиан симметричен, что (как мы видели в главе про матрицы) гарантирует вещественные собственные значения и ортогональные собственные векторы.

- Гессиан рассказывает нам о форме функции вблизи критической точки (где градиент равен нулю):

    - Если $H$ положительно определён (все собственные значения положительны), точка является **локальным минимумом** — поверхность изгибается вверх во всех направлениях, как чаша.
    - Если $H$ отрицательно определён (все собственные значения отрицательны), точка является **локальным максимумом** — поверхность изгибается вниз, как перевёрнутая чаша.
    - Если у $H$ есть и положительные, и отрицательные собственные значения, точка является **седловой точкой** — поверхность изгибается вверх в одних направлениях и вниз в других, как горный перевал.

- **Многомерное цепное правило** расширяет цепное правило на функции нескольких переменных. Если $z = f(x, y)$, где $x = g(t)$ и $y = h(t)$, то:

$$\frac{dz}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}$$

- Каждый путь от $t$ к $z$ вносит свой вклад: частная производная вдоль этого пути, умноженная на производную промежуточной переменной по $t$.

- Например, если $z = x^2 y + 3x - y^2$, $x = \cos(t)$, $y = \sin(t)$:

$$\frac{dz}{dt} = (2xy + 3)(-\sin t) + (x^2 - 2y)(\cos t)$$

- Помимо вычисления производных вручную, существует три подхода:

    - **Численное дифференцирование**: приблизить $f'(x) \approx \frac{f(x+h) - f(x-h)}{2h}$ для малого $h$. Просто, но зашумлённо и неточно.
    - **Символьное дифференцирование**: алгебраически применить правила дифференцирования, чтобы получить точную формулу. Может производить выражения, растущие экспоненциально.
    - **Автоматическое дифференцирование (autodiff)**: отслеживает цепочку операций и вычисляет точные производные эффективно. Именно это используют JAX, PyTorch и TensorFlow. Это даёт точные числовые значения (не приближённые) без раздутых символьных выражений.

## Практические задания (используйте CoLab или блокнот)

1. Вычислите градиент $f(x, y) = x^2 y + 3x - 2y$ в точке $(1, 2)$ с помощью `jax.grad`. Поскольку $f$ принимает векторный вход, используйте `jax.grad` с `argnums`.
```python
import jax
import jax.numpy as jnp

def f(x, y):
    return x**2 * y + 3*x - 2*y

df_dx = jax.grad(f, argnums=0)
df_dy = jax.grad(f, argnums=1)

x, y = 1.0, 2.0
print(f"∂f/∂x = {df_dx(x, y):.4f}  (expected: {2*x*y + 3:.4f})")
print(f"∂f/∂y = {df_dy(x, y):.4f}  (expected: {x**2 - 2:.4f})")
```

2. Вычислите якобиан векторнозначной функции с помощью `jax.jacobian`. Сравните с ручным вычислением.
```python
import jax
import jax.numpy as jnp

def F(x):
    return jnp.array([x[0]**2 + x[1], x[0] * x[1]**2])

J = jax.jacobian(F)
x = jnp.array([1.0, 2.0])
print(f"Jacobian at (1,2):\n{J(x)}")
# Expected: [[2*x[0], 1], [x[1]**2, 2*x[0]*x[1]]] = [[2, 1], [4, 4]]
```

3. Вычислите гессиан $f(x, y) = x^3 + 2xy^2 - y^3$ с помощью `jax.hessian` и убедитесь, что он симметричен.
```python
import jax
import jax.numpy as jnp

def f(xy):
    x, y = xy[0], xy[1]
    return x**3 + 2*x*y**2 - y**3

H = jax.hessian(f)
point = jnp.array([1.0, 2.0])
hess = H(point)
print(f"Hessian:\n{hess}")
print(f"Symmetric: {jnp.allclose(hess, hess.T)}")
# Expected: [[6x, 4y], [4y, 4x-6y]] = [[6, 8], [8, -8]]
```

4. Постройте минимальный движок автоматического дифференцирования с нуля.
    - Каждый `Var` отслеживает своё значение и то, как распространять градиенты назад через цепное правило.
    - Попробуйте расширить его дополнительными операциями (деление, возведение в степень и т. д.).
    - Это основы того, как были спроектированы JAX, PyTorch и NumPy.
```python
class Var:
    def __init__(self, val, children=(), backward_fn=None):
        self.val = val
        self.grad = 0.0
        self.children = children
        self.backward_fn = backward_fn

    def __add__(self, other):
        out = Var(self.val + other.val, children=(self, other))
        def _backward():
            self.grad += out.grad    # d(a+b)/da = 1
            other.grad += out.grad   # d(a+b)/db = 1
        out.backward_fn = _backward
        return out

    def __mul__(self, other):
        out = Var(self.val * other.val, children=(self, other))
        def _backward():
            self.grad += other.val * out.grad  # d(a*b)/da = b
            other.grad += self.val * out.grad  # d(a*b)/db = a
        out.backward_fn = _backward
        return out

    def backward(self):
        # topological sort then propagate gradients
        # we will go through this in data structures and algorithms
        order, visited = [], set()
        def topo(v):
            if v not in visited:
                visited.add(v)
                for c in v.children:
                    topo(c)
                order.append(v)
        topo(self)
        self.grad = 1.0
        for v in reversed(order):
            if v.backward_fn:
                v.backward_fn()

# f(x, y) = x*x*y + x  at (3, 2)
x = Var(3.0)
y = Var(2.0)
f = x * x * y + x       # = 3*3*2 + 3 = 21

f.backward()
print(f"f = {f.val}")           # 21.0
print(f"df/dx = {x.grad}")     # 2*x*y + 1 = 13.0
print(f"df/dy = {y.grad}")     # x*x = 9.0
```
